# 6. Hafta Raporu

Bu hafta Docker, Docker Compose, config yönetimi, CI/CD ve deployment konuları üzerinde
çalışıldı. Multi-stage Dockerfile hazırlandı ve container'ın non-root kullanıcıyla
çalışması sağlandı. PostgreSQL, backend ve frontend servisleri Docker Compose ile
tanımlandı ve healthcheck kullanımı incelendi.

Environment variable kullanımı, `.env.example`, secret yönetimi ve development/production
ortam ayrımı çalışıldı. GitHub Actions kullanılarak build ve artifact oluşturan basit bir
CI pipeline hazırlandı.

Haftanın sonunda blue-green, canary ve rolling deployment yaklaşımları incelendi ve
rollback adımları yazıldı. Java SE tarafında Lambda, Functional Interface, Stream API,
Optional ve Date/Time API konuları; frontend tarafında ise modern HTML, CSS, Bootstrap,
JavaScript ve TypeScript örnekleri uygulandı.
