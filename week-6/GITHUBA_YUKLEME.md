# GitHub'a Yükleme

Bu klasörü GitHub repository olarak yüklemek için:

```bash
git init
git add .
git commit -m "feat: complete week 6 internship tasks"
git branch -M main
git remote add origin REPOSITORY_URL
git push -u origin main
```

Gerçek `.env` dosyasını GitHub'a yükleme. Repoda yalnızca `.env.example` bulunmalıdır.
