# 6. Hafta Çalışmaları

Bu repository 6. hafta boyunca yapılan Docker, Docker Compose, config/secret yönetimi,
CI/CD, Java SE ve frontend çalışmalarını içermektedir.

## Günler

- Gün 26: Dockerfile ve reproducible build
- Gün 27: Docker Compose, network ve healthcheck
- Gün 28: Config/secret yönetimi
- Gün 29: CI pipeline, cache ve artifact
- Gün 30: Deployment stratejileri ve rollback

## Çalıştırma

```bash
cp .env.example .env
docker compose up --build
```

Java örnekleri `java/` klasöründedir.
Frontend örnekleri `frontend/` klasöründedir.
Haftalık araştırma ve raporlar `docs/` klasöründedir.
