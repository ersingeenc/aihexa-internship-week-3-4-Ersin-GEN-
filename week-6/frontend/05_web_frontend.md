# Web Frontend Teslimi - Gün #26-#30

Bu klasörde haftanın frontend konuları tek küçük demo içerisinde birleştirilmiştir.

Kullanılan konular:

- HTML5: `fieldset`, `legend`, `autocomplete`, `multiple`, `file`
- CSS3: `clamp()`, `aspect-ratio`, `object-fit`, container query
- Bootstrap 5: validation ve dropdown
- JavaScript: `try/catch/finally`, `Promise.allSettled`
- Form doğrulama ve kullanıcıya hata mesajı gösterme

`index.html` dosyası tarayıcıda açılarak incelenebilir.
