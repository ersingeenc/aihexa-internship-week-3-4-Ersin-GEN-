# Java SE #21 - List ve ArrayList

`List`, sıralı koleksiyon davranışını tanımlayan bir interface'tir. `ArrayList` ise bu interface'in dinamik dizi tabanlı yaygın implementasyonudur. Örnekte ekleme, okuma, güncelleme ve silme işlemleri yapılır.

Çalıştırma:

```bash
javac ListArrayListExample.java
java ListArrayListExample
```

Kaynak: https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/List.html
