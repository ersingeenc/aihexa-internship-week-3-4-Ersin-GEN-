# Web Frontend #22 - BEM ve Sürdürülebilir CSS

**BEM (Block, Element, Modifier)**, CSS sınıflarını bileşen odaklı ve tahmin edilebilir adlandırmaya yardımcı olur. Örneğin `profile-card`, `profile-card__title` ve `profile-card--featured` yapısı kullanılır.

Utility sınıfları tek bir küçük görevi tekrar kullanılabilir biçimde çözer. Örneğin `u-text-center` yalnızca metni ortalar. Component CSS ise bir bileşenin kendi görsel sınırını korur.

Demo, dağınık ve genel selectorlar yerine BEM yapısıyla hazırlanmış profil/test kartı içerir.
