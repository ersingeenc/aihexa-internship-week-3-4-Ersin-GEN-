# Java SE #24 - Generics

Generics, sınıf ve metotlarda kullanılacak tipi parametreleştirerek compile-time type safety sağlar. `Object` kullanıldığında cast ihtiyacı ve runtime type hatası riski artar. Generic örnekte aynı `Box<T>` sınıfı farklı tiplerle güvenli şekilde kullanılır.

Kaynak: https://docs.oracle.com/javase/tutorial/java/generics/
