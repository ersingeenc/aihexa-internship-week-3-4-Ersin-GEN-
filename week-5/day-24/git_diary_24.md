# Git Günlüğü #24 - Pull Request / Merge Request

İyi bir PR/MR açıklaması değişikliğin neden yapıldığını, nelerin değiştiğini, nasıl test edildiğini ve bilinen riskleri açıklar.

Bu repository'de `.github/pull_request_template.md` dosyası aşağıdaki alanları içerir:

- Amaç
- Değişiklikler
- Test checklist'i
- Riskler
- Kanıt

Bu yapı code review sırasında inceleyenin bağlamı hızlı anlamasına yardımcı olur.

Kaynak: https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests
