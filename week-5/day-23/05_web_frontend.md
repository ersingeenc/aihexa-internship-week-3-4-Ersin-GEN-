# Web Frontend #23 - Bootstrap 5 Özelleştirme

Bootstrap, hazır component ve utility sınıflarıyla hızlı arayüz geliştirmeyi sağlar. Kontrollü özelleştirmede framework'ün tamamını rastgele override etmek yerine CSS variables veya küçük scoped sınıflar tercih edilebilir.

Demo, Bootstrap `card`, `badge`, `btn`, grid ve spacing utility sınıflarını kullanır. `:root` altında tanımlanan proje değişkenleri ile kurumsal görünüm desteklenmiştir.

Kaynak: https://getbootstrap.com/docs/5.3/customize/css-variables/
