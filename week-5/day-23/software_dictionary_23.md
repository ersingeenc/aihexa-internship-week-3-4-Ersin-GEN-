# Yazılım Sözlüğü #23 - Code Smell

Code smell, kodun kesin olarak hatalı olduğunu değil; bakım, değişiklik veya test sırasında sorun çıkarma ihtimali olan bir tasarım işaretini ifade eder. Uzun metotlar çok fazla sorumluluk taşıyabilir. Tekrarlanan kod aynı düzeltmenin birden fazla yerde yapılmasına yol açabilir. Büyük sınıflar ise farklı sorumlulukların tek yerde toplanmasına neden olabilir. Code smell görüldüğünde davranış korunarak refactoring düşünülmelidir.
