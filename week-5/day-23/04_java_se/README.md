# Java SE #23 - Map ve HashMap

`Map`, anahtar-değer ilişkisini temsil eder. `HashMap`, anahtar üzerinden hızlı erişim sağlayan yaygın implementasyondur. Örnekte kullanıcı ID'si anahtar, kullanıcı adı değer olarak tutulur.
