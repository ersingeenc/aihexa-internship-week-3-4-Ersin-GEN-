# Java SE #25 - Comparable ve Comparator

`Comparable`, sınıfın doğal sıralama kuralını kendi içinde tanımlar. `Comparator` ise sınıfı değiştirmeden farklı harici sıralama kuralları tanımlamayı sağlar. Örnekte öğrenciler önce ada göre doğal, sonra puana göre harici olarak sıralanır.
