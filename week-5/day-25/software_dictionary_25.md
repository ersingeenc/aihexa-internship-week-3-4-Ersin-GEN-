# Yazılım Sözlüğü #25 - Semantic Versioning

Semantic Versioning sürümü `MAJOR.MINOR.PATCH` şeklinde ifade eder.

- **MAJOR:** Geriye dönük uyumsuz değişiklik. Örnek `1.4.2 -> 2.0.0`
- **MINOR:** Geriye dönük uyumlu yeni özellik. Örnek `1.4.2 -> 1.5.0`
- **PATCH:** Geriye dönük uyumlu hata düzeltmesi. Örnek `1.4.2 -> 1.4.3`

Bu yaklaşım API tüketicisine değişikliğin risk seviyesi hakkında hızlı bilgi verir.

Kaynak: https://semver.org/
