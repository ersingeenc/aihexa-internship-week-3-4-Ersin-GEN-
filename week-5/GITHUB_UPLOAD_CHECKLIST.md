# GitHub Yükleme Checklist

- [ ] Repository köküne tüm paket içeriğini ekle.
- [ ] `.gitignore` dosyasının bulunduğunu kontrol et.
- [ ] `git status` ile secret veya gereksiz build çıktısı olmadığını kontrol et.
- [ ] Java 17 örneklerini çalıştır.
- [ ] Docker + Maven varsa `mvn verify` çalıştır.
- [ ] Her `day-XX/frontend` demosunu tarayıcıda aç.
- [ ] Mentor özellikle görsel kanıt istiyorsa gerçek ekran görüntülerini ilgili `frontend` klasörüne ekle.
- [ ] Anlamlı commit mesajları kullan.
- [ ] PR açarken `.github/pull_request_template.md` alanlarını doldur.
- [ ] Gün 25 için `.github/ISSUE_TEMPLATE/bug_report.md` örneğini GitHub Issue olarak açıp kanıt oluştur.

## Önerilen komutlar

```bash
git add .
git commit -m "docs: complete week 5 testing and quality deliverables"
git push origin main
```
