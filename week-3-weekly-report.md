# Pazartesi Günlük Çalışma Raporu

## Pazartesi Ne Öğrendim?

Pazartesi günü aşağıdaki konular hakkında çalışmalar yaptım:

* Markdown etiketleri ve kullanım alanları
* Git ve GitHub
* Repository yapısı ve kullanım amacı
* Branch kavramı
* Merge Conflict
* Pull Request
* Pull Request ile Merge arasındaki fark
* Doğru ve anlaşılır commit mesajı yazma
* `.gitignore` dosyasının kullanım amacı
* Issue kavramı
* Bir yazılım ekibinde GitHub kullanımı
* Proje klasör yapısının önemi

Bu çalışmalar sayesinde Git ve GitHub’ın bir yazılım projesindeki temel kullanım mantığını daha iyi anladım.

---

## En Çok Zorlandığım Konu Neydi?

Genel olarak konuları öğrenirken çok fazla zorlanmadım. Ancak **Issue** konusu başlangıçta bana biraz farklı ve anlaşılması zor geldi.

Issue kavramını daha iyi anlayabilmek için iki farklı kaynaktan araştırma yapmam gerekti. Farklı kaynakları inceledikten sonra Issue’ların projelerde hata bildirmek, görev oluşturmak, geliştirme önerisi sunmak ve ekip içerisindeki işleri takip etmek amacıyla kullanıldığını öğrendim.

## Bir Sonraki Gün Neye Çalışacağım?

Bir sonraki gün aşağıdaki konulara çalışmayı planlıyorum:

# Salı Günlük Çalışma Raporu

## Salı Günü Ne Öğrendim?

Salı günü Spring Boot ve backend geliştirme hakkında çalışmalar yaptım.

Öğrendiğim başlıca konular:

* Spring Boot ve backend
* REST API
* Controller, Service ve Repository
* Entity, DTO, JPA ve Hibernate
* Maven ve `pom.xml`
* `application.properties` ve `application.yml`
* GET, POST, PUT ve DELETE metotları
* HTTP durum kodları
* Backend hata mesajları ve stack trace

Ayrıca bir kullanıcı kayıt sistemindeki veri akışını öğrendim:

```text
React Form → JSON → Controller → Service → Repository → Database → Response
```

## En Çok Zorlandığım Konu Neydi?

En çok stack trace yorumlama konusunda zorlandım. Hata türü, hata mesajı, `Caused by`, sınıf adı ve satır numarasına bakarak hatanın bulunabileceğini öğrendim.
