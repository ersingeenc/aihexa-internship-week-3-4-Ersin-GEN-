# Pazartesi Günlük Çalışma Raporu

## Pazartesi Ne Öğrendim?

Pazartesi günü **AIHEXA QR Kod Oluşturma Modülü** üzerine çalışma yaptım.

Bu çalışma kapsamında:

* QR Kod Oluşturma Modülünün amacı
* Modülü kullanacak kullanıcı ve admin rolleri
* Kullanıcının modül içerisinde yapabileceği işlemler
* Adminin modül içerisinde gerçekleştirebileceği işlemler
* Modülün AIHEXA’ya sağlayacağı katkılar
* Frontend tarafında gerekli ekranlar
* Backend tarafında yapılması gereken işlemler
* Database içerisinde tutulması gereken bilgiler
* Modülün eğitim, sosyal medya ve SEO alanlarına katkıları
* Modülün genel çalışma mantığı

konularını araştırdım ve proje planını oluşturdum.

Bu çalışma sayesinde bir modül geliştirilmeden önce ihtiyaçların belirlenmesi ve frontend, backend ve database taraflarının planlanmasının önemini daha iyi anladım.

---

## En Çok Zorlandığım Konu Neydi?

Genel olarak modül planını hazırlarken çok fazla zorlanmadım.

Ancak modülün **backend ve database tarafında hangi işlemlerin ve bilgilerin bulunması gerektiğini belirlemek** diğer konulara göre daha fazla düşünmemi gerektirdi.

Modülün sadece QR kod oluşturmasından ibaret olmadığını; oluşturulan QR kodların kaydedilmesi, listelenmesi, görüntülenmesi ve yönetilmesi gibi işlemlerin de planlanması gerektiğini öğrendim.

# Salı Günlük Çalışma Raporu

## Salı Ne Öğrendim?

Salı günü **AIHEXA QR Kod Oluşturma Modülünün API analizi** üzerine çalışma yaptım.

Bu çalışma kapsamında:

* API Endpoint kavramı
* Request ve Response yapıları
* JSON Request Body ve JSON Response Body
* CRUD işlemleri
* HTTP metotları
* HTTP Status Kodları
* Backend validasyon işlemleri
* Başarılı ve hatalı response yapıları
* Olası backend hataları
* QR Kod Modülü için gerekli API endpointleri

konularını araştırdım.

QR Kod Modülü için QR kod oluşturma, listeleme, detay görüntüleme, güncelleme ve silme işlemlerinde kullanılabilecek API endpointlerini belirledim.

Bu çalışma sayesinde frontend ile backend arasındaki iletişimin API endpointleri üzerinden nasıl gerçekleştiğini ve backend tarafında gelen isteklerin nasıl kontrol edilerek cevaplandırıldığını daha iyi anladım.

---

## En Çok Zorlandığım Konu Neydi?


Farklı işlemlerde **hangi HTTP metodunun ve HTTP status kodunun kullanılması gerektiğini belirlemek** diğer konulara göre daha fazla düşünmemi gerektirdi.

Ayrıca backend tarafında gelen verilerin validasyonunun yapılmasının ve hata durumlarında frontend'e anlaşılır response gönderilmesinin önemli olduğunu öğrendim.
